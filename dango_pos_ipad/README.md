# だんご🍡 販売カウンター v5.2

## v5.2 追加機能

### 1. 取引メモ
「最近の記録」または取引履歴をタップすると取引詳細を開きます。

追加可能:
- メモ本文
- 「対応完了」チェック

例:
- 支払済み。あとで取りに来る
- 取り置き
- 返金確認待ち

### 2. 要対応表示
メモがあり「対応完了」がOFFの場合:
- 最近の記録を薄い黄色で強調
- `📝 要対応` バッジを表示

「対応完了」をONにすると:
- 黄色表示を解除
- 要対応アイコンを解除
- メモ本文は残す
- `noteResolvedAt` に対応完了日時を保存

チェックをOFFに戻すと再び要対応表示になります。

### 3. CSV
自由入力メモに対応するため、CSV処理をRFC的なクォート形式へ変更しました。

対応:
- カンマ
- ダブルクォート
- 改行

CSVに追加:
- note
- note_updated_at
- note_resolved
- note_resolved_at

旧v1～v5.1形式のCSVも読み込み可能です。

### 4. 全データ表示タブ
ダッシュボードの次に「全データ表示」タブを追加。

表示列:
- 日時
- 4桁キー
- しょうゆ
- みたらし
- 合計本数
- 単価
- 売上
- 取引状態
- メモ状態
- メモ
- メモ更新日時
- 対応完了日時

行をタップすると取引詳細を開けます。

### 5. 4桁キー検索
取引ID末尾4桁を検索できます。

例:
`H58N`

入力は最大4文字・英数字・大文字に自動整形します。
部分一致にも対応しています。
