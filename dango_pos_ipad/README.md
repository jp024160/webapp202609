# だんご🍡 販売カウンター v5.3

## ダッシュボード変更
- iPad横向きで販売入力画面と同程度の縦幅に収まるよう圧縮
- 上段左：販売本数の推移（15分毎）
  - しょうゆ / みたらし積み上げ棒グラフ
  - 表示可能なサイズでは各SKU本数を棒内表示
  - 棒の上に合計本数
- 上段右：取引件数の推移（15分毎）
  - 折れ線グラフ
- 15分グラフの時間軸は可変
  - 取引なし：09:00～15:00
  - 取引あり：最初の取引を含む15分枠～最後の取引を含む15分枠
- 下段左：商品別構成比を半円ゲージへ変更
  - しょうゆ＝茶色
  - みたらし＝オレンジ
- 時間帯別サマリーを削除
- 最近の取引を削除
- 下段右：メモがあり、対応未完了の登録済み取引一覧
  - 時間
  - しょうゆ本数
  - みたらし本数
  - 合計本数
  - メモ内容
  - 行タップで取引詳細を表示

## 更新方法
GitHub Pages の `dango_pos_ipad` フォルダ内を v5.3 のファイルで置き換えて Commit してください。
特に `index.html` と `sw.js` を更新してください。

反映後：
1. Safariで公開URLを再読み込み
2. ホーム画面アプリを完全終了
3. 再起動
