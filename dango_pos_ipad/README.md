# だんご🍡 販売カウンター Ver. 6.2

## 新規：記録一覧（大）
販売入力タブの隣に、大きな販売記録一覧タブを追加しました。

表示列は以下の5項目だけです。
- 日時
- 4桁キー
- しょうゆ
- みたらし
- 合計本数

### 表示
- タブ直下に説明ヘッダを置かず、すぐ表を表示
- 日時は降順（最新が最上段）
- 日時形式は `MM/DD hh:mm`
- 本数は「本」を付けず数字のみ
- しょうゆ・みたらし・合計本数を4桁キーより大幅に大きく表示
- 1行を高くして、1画面の行数より視認性を優先
- しょうゆ＝既存の茶色
- みたらし＝既存のオレンジ
- 合計＝黒

### キータップ
4桁キーをタップすると、Ver.6.1の既存取引詳細を開きます。
そこからメモの表示・編集、対応完了、取引取消ができます。

### 取消済み
この一覧には取消済み取引を表示しません。
取消済みを含む監査データは「全データ表示」とCSVに保持されます。

## 既存機能
Ver.6.1の販売入力、4桁キー、ダッシュボード、15分/1時間切替、
全データ表示、CSV、メモ、取消確認、効果音は変更していません。
