# だんご🍡 販売カウンター Ver. 6.3

## 1. データ形式：受け渡し済み
各取引に `handedOver` (boolean) を追加しました。

- 新規取引は `false`
- 既存のVer.6.2以前の取引は項目がなくても `false` として扱います
- IndexedDBのDB名・Object Storeは変更していないためDBバージョンアップは不要です
- CSVに `handed_over` 列を追加
- 旧CSVには列がなくても `false` として復元できます

## 2. 記録一覧（大）
従来の行高・大きな本数表示を維持したまま「受け渡し済み」列を追加しました。

- チェックON → 即保存
- チェック済み行 → グレーアウト
- チェックOFF → 元の表示へ戻る
- 4桁キーのタップ → 従来どおり取引詳細・メモを表示
- 取消済み取引は従来どおり一覧には表示しません

## 3. 販売入力：最近の記録
中央～右の合計・お会計・しょうゆ・みたらし・操作ボタン配置は変更していません。
左の「最近の記録」だけを変更しました。

- Pane幅を 280px → 230px に縮小
- 日時を非表示
- 表示は `4桁キー / しょうゆ本数 / みたらし本数 / 受け渡し済み`
- 「しょうゆ」「みたらし」の文字は表示せず数字のみ
- しょうゆ数字＝茶色
- みたらし数字＝オレンジ
- 数字を大きく表示
- 受け渡し済みチェックON → 行をグレーアウト
- 「全て見る」から記録一覧（大）へ移動
- 未完了メモの黄色強調は、未受け渡し行では従来どおり維持

## 全データ表示
監査用の全データ表にも「受け渡し済み」列を追加し、チェック状態を確認・変更できます。
取消済み取引ではチェック変更不可です。

## 互換性
- 既存 `DangoPOS` IndexedDBをそのまま使用
- Ver.6.2以前の既存取引データをそのまま読めます
- Ver.6.2以前のCSVを読み込み可能
- 効果音、メモ、対応完了、取消、15分/1時間切替など既存機能は維持
