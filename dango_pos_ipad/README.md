# だんご🍡 販売カウンター Ver. 6

## Ver.6 の変更

### ダッシュボード
- 現行の色・カード配置・縦幅を維持
- 「平均単価」KPIを削除
- 同じ位置に `15分毎 / 1時間毎` のグラフ集計切替ボタンを追加
- 左上「販売本数」と右上「取引件数」は同時に切替
- 取引件数は従来どおり折れ線グラフ
- 未完了メモ一覧に「キー」列を追加
- しょうゆは茶色、みたらしはオレンジの既存配色を維持

### 4桁キー
- 内部の transaction_id は従来どおり変更しない
- Ver.6以降の新規取引に、人が検索するための4桁数字キーを追加
- その日の新規取引は `0001`, `0002`, `0003` ... の連番
- 取消済み取引のキーは再利用しない
- Ver.5以前の既存取引には新しいキーを後付けしないため `----` 表示
- 全データ表示の検索欄は数字のみ入力可能

### タブ / CSV
- 「時間帯履歴」タブをナビゲーションから削除
- CSV出力 / CSV復元は「設定 > データ管理」に移動
- Ver.6 CSVに `display_key` 列を追加
- Ver.5以前のCSVも引き続き復元可能

### 取引詳細
指定どおり縦配置へ変更:
1. 取引内容
2. 取引取消
3. メモ欄
4. メモ保存
5. 対応完了チェック
6. 閉じる

- 「対応完了」はチェック変更時に即保存
- メモが未保存の状態では対応完了にできない
- メモ内容は対応完了後も保持

### その他
- 効果音ON/OFF、テスト再生、MP3再生処理はVer.5.5の動作済みロジックを維持
- IndexedDB名 `DangoPOS` と既存ストアは変更していないため、既存取引データを保持
- JavaScript構文チェック実施済み
