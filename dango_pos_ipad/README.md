# だんご🍡 販売カウンター Ver. 6.1

Ver.6の修正版です。

## 修正1：最近の記録の4桁キー
販売入力タブの「最近の記録」Paneに、
旧transaction_id末尾4文字ではなく、Ver.6の人間用4桁数字キーを表示します。

例:
- 0001
- 0002
- 0237

Ver.5以前の取引など `key4` を持たない既存取引は `----` と表示します。

## 修正2：取引取消のキャンセル
取引詳細で「取引取消」を押すと確認画面を表示します。

確認画面:
- 「実行」 → 取引を取消
- 「閉じる」 → 取消操作だけキャンセルし、取引詳細へ戻る

確認画面を閉じて取引詳細へ戻った場合、
まだ「メモ保存」を押していない入力途中のメモ内容も保持します。

確認画面の背景部分をタップした場合も、
「閉じる」と同様に取引詳細へ戻ります。

## その他
- Ver.6の4桁キー、15分/1時間切替、CSV、配色、レイアウト、効果音などは変更していません。
- IndexedDB `DangoPOS` の構造は変更していません。
- JavaScript構文チェック済み。
