# だんご🍡 販売カウンター v5.5 修正版

## 修正方針
動作していた v5.4 をベースに、効果音機能だけを最小限追加しました。

## v5.5旧版が動かなかった原因
追加したJavaScriptに構文エラーがあり、スクリプト全体が読み込まれませんでした。
そのため：
- ＋ / −
- タブ切替
- 販売登録
などJavaScriptを使う機能がすべて停止していました。

## 今回の変更
- v5.4の販売・タブ・ダッシュボード・メモ等のロジックを維持
- 設定タブに「効果音 ON/OFF」
- デフォルト ON
- 設定値をIndexedDBに保存
- 「テスト再生」を追加
- 「受領済・登録」のタップ時、最初のawaitより前にMP3を無音再生してSafariにユーザー操作として認識させる
- DB保存成功後にMP3を先頭から通常音量で再生
- DB保存失敗時は無音再生を停止して音を出さない
- `cash_register.mp3` はService Workerでキャッシュ
- JavaScriptをNode.js `--check` で構文検証済み

## 更新後の確認
1. GitHubへファイルを置き換えてCommit
2. Safariで公開URLを再読み込み
3. ホーム画面アプリを完全終了して再起動
4. まず「＋」とタブ切替が正常か確認
5. 設定 → 効果音 → テスト再生
6. 販売入力 → 確定 → 受領済・登録で音を確認
