# だんご🍡 販売カウンター v3

## 変更点
- 「販売入力」「時間帯履歴」の2タブ構成
- ヘッダを「だんご🍡」に簡素化
- 販売入力画面：
  - 左：最近の記録（画面下端まで）
  - 中央：合計 / お会計
  - 右：しょうゆ / みたらし
- ボタン：左から「注文取消・リセット」「受領済・登録」「確定」
- 注文は「確定」→「受領済・登録」の2段階
- 確定前の数量・金額は黒
- 確定すると数量・金額をビビッドな青に変更し、＋/−を無効化
- 「受領済・登録」で初めて販売データを保存
- リセット時に確認ダイアログを表示
- 最近の記録をタップすると、その取引を取消可能
- 取引取消は物理削除せず `cancelled` として内部履歴に保持
- 取消済取引は売上・本数・時間帯集計から除外
- 時間帯履歴タブでは取消済取引も監査履歴として表示
- CSVに status / cancelled_at 列を追加
- 旧v1 CSVも復元可能
- 旧アプリで保存済みの取引は status 未設定でも active として扱う

## iPad / GitHub Pagesへの更新
GitHubの `dango_pos_ipad` フォルダ内を、このZIPの以下5ファイルで置き換えてください。

- index.html
- sw.js
- manifest.webmanifest
- icon-180.png
- icon-512.png

GitHub Pagesへの反映後、iPadのWebアプリを一度終了して再起動してください。
古い画面が残る場合は、Safariで公開URLを開いて再読み込みしてからホーム画面のアプリを再起動してください。

## 保存データ
販売データはiPadのIndexedDBに保存します。
既存の `DangoPOS` データベースを継続使用するため、v1から更新しても既存取引を読めます。

## CSV
出力例：
`dango_sales_2026-08-31_191500.csv`

取消済取引もCSVに残ります。
