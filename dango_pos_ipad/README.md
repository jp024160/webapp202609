# 学園祭 団子販売カウンター

## 仕様
- iPad横向き推奨
- しょうゆ / みたらし の2SKU
- 各1本120円
- 現金決済のみ
- 「＋ / −」で1会計の注文数量を入力
- 合計本数・販売金額を即時表示
- 「販売確定」で1取引として端末内（IndexedDB）に保存
- 販売確定時刻を自動保存
- 本日累計、SKU別累計、時間帯別売上を表示
- 直前取引の取消
- CSVスナップショット出力
- CSVから履歴を復元
- PWA対応（HTTPSで公開するとホーム画面追加・オフライン利用可）

## CSVファイル名
例:
dango_sales_2026-08-31_142530.csv

出力するたびに日時が変わるため、既存ファイルを上書きせず履歴を残しやすい設計です。

## iPadで使う最も簡単な方法
このフォルダ一式を HTTPS の静的Webホスティングに配置します。
GitHub Pages / Netlify / Cloudflare Pages などが利用できます。

Safariで公開URLを開く:
1. 共有ボタンをタップ
2. 「ホーム画面に追加」
3. 作成された「団子販売」アイコンから起動

初回読み込み後はService Workerによりオフライン利用できます。
販売データ自体はiPad内のIndexedDBに保存されます。

## 重要
Safariの履歴・Webサイトデータを消去すると、iPad内に保存された販売履歴も消える可能性があります。
学園祭中は定期的に「CSV出力（スナップショット）」を押してバックアップしてください。
