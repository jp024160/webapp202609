# だんご🍡 販売カウンター v5.0

## v5.0 変更点
- 「ダッシュボード」タブを追加
- ヘッダ右上に `Ver. 5.0` 表示
- KPI：売上金額、販売本数、SKU別本数、取引件数、平均単価
- 販売本数の推移（時間別）：しょうゆ / みたらし積み上げ
- 取引件数推移（時間別）：折れ線
- 商品別構成比（本数）
- 時間帯別サマリー
- 直近の販売本数推移（10分単位）
- 最近の取引（最新5件）
- 取消済み取引はダッシュボード集計から除外

## 上段グラフの時間軸
可変です。

取引がある場合：
- 最初の販売が発生した時間帯から
- 最後の販売が発生した時間帯まで
- 1時間単位で表示

取引がまだない場合：
- 09:00〜15:00 を初期表示

例：
- 最初 09:12 / 最後 14:48 → 09:00〜14:00
- 08:55に販売 → 08:00から自動表示
- 16:10まで販売 → 16:00まで自動延長

## 直近10分グラフ
最新の登録済み取引時刻を基準に、直近7個の10分区間を表示します。
各バーはしょうゆ / みたらしの販売本数です。
