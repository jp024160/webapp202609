# だんご🍡 販売カウンター v4

## v4 変更点
- 「合計」「お会計」の数字を1段階大きく表示
- 「設定」タブを追加
- 共通単価を設定画面から変更可能（初期値120円）
- 単価は「確定・反映」を押してから有効
- 各取引に登録時の単価を保存
- 途中で単価を変更しても、過去取引の金額は変更しない
- 確定済み・未登録の注文は確定時点の単価を保持
- 時間帯別売上・本日売上は各取引に保存された実際の金額を合算
- 「受領済・登録」は確定前：白地＋緑字
- 「受領済・登録」は確定後：緑地＋白字
- 「すべての記録をリセット」を設定タブに追加
- 全削除前に確認ポップアップを表示
- 全削除を実行すると、削除直前に全データのCSV出力を開始してから取引履歴を削除
- 全記録削除後も単価設定は保持
- 取消済み取引もCSVバックアップに含む
- 旧データで unitPrice がない取引は、保存済み totalPrice / totalQty から単価を復元

## 更新方法
GitHub Pages の `dango_pos_ipad` フォルダ内を、ZIP内のファイルで置き換えてコミットしてください。

必須:
- index.html
- sw.js
- manifest.webmanifest
- icon-180.png
- icon-512.png

反映後、Safariで公開URLを一度再読み込みしてからホーム画面のWebアプリを再起動してください。
Service Workerのキャッシュ名はv4へ更新済みです。

## 2日間販売の推奨運用
1日目終了時:
1. 設定 → 「すべての記録をリセット」
2. 確認画面で実行
3. CSVスナップショットの保存を確認
4. 取引履歴が0件になったことを確認

2日目はそのまま新規記録を開始できます。
単価設定はリセットされません。
