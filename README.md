# だんご🍡 販売カウンター v5.1

## v5.1 修正
- ヘッダ右上のバージョンを `Ver. 5.1` に更新
- 商品別構成比（ドーナツグラフ）の「しょうゆ / みたらし」色対応を修正
  - しょうゆ = 茶色
  - みたらし = オレンジ
- 以下2つの積み上げ棒グラフにSKU別の内訳本数を表示
  - 販売本数の推移（時間別）
  - 直近の販売本数推移（10分単位）
- 表示ルール
  - 茶色部分中央：しょうゆ本数
  - オレンジ部分中央：みたらし本数
  - 棒の上：合計本数
  - 棒のセグメントが小さすぎる場合は、可読性を優先して内訳数字を非表示
- Service Workerキャッシュをv5.1へ更新

## 更新方法
GitHub Pagesの `dango_pos_ipad` フォルダ内をv5.1のファイルで置き換えてCommitしてください。
特に `index.html` と `sw.js` を更新してください。
反映後、Safariで公開URLを再読み込みし、ホーム画面アプリを完全終了→再起動してください。
